Matching is case-sensitive within one supported block and collapses only XML whitespace. This report verifies the selected source locations and generated structure, not whether the editor supplied the correct print boundaries. It does not certify all reading systems, overall accessibility, rendering fidelity or the final EPUB 3.4 standard. Limits: 25 MiB input/output, 100 MiB expanded, 200 spine documents, 500 boundaries, plus XML/search-work caps. No external assets are loaded, no source is uploaded and no file is automatically saved.
